# 🚀 Programação IV (Prog-IV)

Repositório dedicado ao armazenamento das atividades práticas, exercícios e trabalhos desenvolvidos durante as aulas da disciplina de **Programação IV**.

---

## 📌 Sobre o Repositório

Este repositório reúne o aprendizado prático ao longo do curso, englobando desde a construção de interfaces web estáticas e dinâmicas até o desenvolvimento de APIs no backend, integração com banco de dados e autenticação JWT.

- **Autora:** [Anna Bheatryz](https://github.com/annabzsantos)
- **Tecnologias Principais:** HTML, CSS, JavaScript, TypeScript, NestJS, MySQL

---

## 🛠️ Tecnologias e Ferramentas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Node.js, NestJS, TypeScript
- **Banco de Dados & ORM:** MySQL, TypeORM
- **Autenticação & Segurança:** JWT (JSON Web Tokens)
- **Consumo de APIs:** Fetch API / RESTful APIs
